# Liste de vérification pour le propriétaire

Avant toute mise en ligne, utilisez uniquement les données de démonstration prévues pour les essais. Connectez-vous à l'administration avec votre compte propriétaire.

## Produits et stock

- [ ] **Produits → Nouveau produit** : saisir le nom, la marque, la catégorie, la description et le prix ; enregistrer le brouillon.
- [ ] Ouvrir la fiche du produit, ajouter des photos et utiliser les flèches pour choisir la première photo.
- [ ] Ajouter un coloris et son stock, puis vérifier le prix et les quantités dans **Produits** et **Stock**.
- [ ] Utiliser **Prévisualiser** pour contrôler le brouillon, puis **Publier**. Vérifier la fiche et sa catégorie sur la boutique.
- [ ] Modifier le prix ou le stock ; vérifier la mise à jour sur la boutique.
- [ ] Utiliser **Archiver**, vérifier le retrait de la vente, puis **Restaurer le produit**. Vérifier qu'il reste en brouillon avant toute nouvelle publication.

## Accueil et contenus

- [ ] **Apparence de l'accueil → Catégories mises en avant** : cocher les catégories et utiliser les flèches pour les classer.
- [ ] Dans **Ordre des sections**, utiliser les flèches, puis **Enregistrer et publier l'accueil**. Ouvrir **Voir l'accueil publié** pour vérifier le résultat.
- [ ] **Paramètres → Sections de l'accueil** : choisir les sections visibles et enregistrer.
- [ ] **Pages et contenu → Bannières** : modifier le titre, le texte, l'image, le bouton et l'ordre ; enregistrer puis contrôler l'accueil public.

## Verres et commandes

- [ ] **Verres et corrections** : vérifier les tarifs et la disponibilité des options, enregistrer un changement et vérifier le configurateur public.
- [ ] Faire valider par un opticien les types de produits compatibles avec chaque verre avant de les activer. Les règles détaillées entre montures et traitements ne sont pas encore configurables : ne pas les supposer validées.
- [ ] Compléter avec l'opticien le tableau de `docs/OPTICAL_COMPATIBILITY_REVIEW.md`. Une case cochée dans l'administration actuelle ne constitue pas une validation professionnelle ; les combinaisons détaillées non vérifiées ne sont pas encore bloquées automatiquement.
- [ ] Effectuer une commande d'essai sans compte, avec paiement à la livraison, puis vérifier le produit, les options, les coordonnées et le statut dans **Commandes**.
- [ ] Vérifier les ordonnances dans **Ordonnances** et les mouvements correspondants dans **Stock**.

Les informations commerciales, coordonnées et textes légaux doivent être contrôlés et approuvés avant une mise en ligne réelle.
